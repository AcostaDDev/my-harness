# v0.1.1 — Model selectors

Interface-only patch before P001
([D231](../DECISIONS.md#d231--packaged-model-suggestions-and-small-ui-patch-releases)).

## Scope

- Global setup (`/setup`): the reviewer's model is a selector of the packaged suggestions for its provider, with
  **Other…** for a hand-written model. A saved model outside the list is shown under **Other…** with its value; a
  suggested model is cleared when the provider changes, a hand-written one is kept.
- Project registration, creation and editing: the executor's models are checkboxes. With a project preset in
  `catalog` mode, only the preset's models; otherwise the suggestions for the executor's provider, the preset's
  models and any model added by hand. Models already in the policy are always shown checked.
- Catalog in `frontend/src/configuration.ts` (`models`, `modelOptions`), next to `efforts`.
- Version `0.1.1` in `pyproject.toml`, `uv.lock`, the FastAPI app, `frontend/openapi.json` and
  `frontend/package.json`/`package-lock.json`. The generated client types do not change.

Not changed: TOML formats and hashes, API schemas, database, configuration assistance (its executor model stays a
free-text field), recipe project versions and the synthetic installer fixtures.
