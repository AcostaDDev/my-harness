# Documentation archive

This repository is developed by hand. Current phase work lives in `docs/phase/`; completed work is separated by
its actual owner rather than being assigned to whichever phase was active when it was delivered.

- [P001 — Metrics Records](phase-001/SUMMARY.md): closed phase, plan/state at closure and its task evidence.
- [One-off development records](one_off_tasks/README.md): completed OT tasks, their supporting handoffs and a
  bounded fix recorded before OT numbering existed.
- [Earlier project history](project-history/README.md): earlier release and development-baseline notes.

Archive location does not imply that every provider/platform was qualified or that every delivery operation was
performed. Historical records retain their own checks and omissions. One-off archive placement follows
[D267](../DECISIONS.md#d267--archive-completed-one-offs-separately-from-active-phase-work); release/integration,
publication and installation remain distinct under D242.

The owner explicitly authorized 17 relative navigation-target changes in three P001 Markdown records on
2026-10-29 to preserve links after this relocation. Their historical text/results and all other P001 artifacts stay
unchanged. This exception does not authorize rewriting frozen run histories, snapshots or versioned source data.
